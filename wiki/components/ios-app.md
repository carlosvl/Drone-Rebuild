# iOS app (DroneRemote)

SwiftUI, iOS 17+, landscape. Xcode project generated by xcodegen from `project.yml`
(the `.xcodeproj` is gitignored).

- `DroneLink`: `NWConnection` UDP, sends a [setpoint](crtp-link.md) every 20 ms.
  Limits: ±15° roll/pitch, ±120°/s yaw, thrust ≤ 60000.
- Arm only at throttle ≤ 5%. Leaving the app (scene not active) disarms.
- Tests: `CRTPTests` check the packet bytes; pass on the iPhone 17 Pro simulator (2026-11-09).
- Not yet run against real firmware. No battery readout yet.
